## 状态没保存

### 症状

- 你标了「通过」，刷新页面或关浏览器后状态不见了
- 导出的报告里你的标注没出现

### 原因 1：离线模式，没导出

**最常见原因**。casemap 离线模式的数据存在**浏览器本地存储**（`localStorage`）。**关掉浏览器或清空浏览器缓存 = 数据丢失**。

**解决**：

- ✅ 每测完一段就点 **「Export Status」** 按钮，把文件存到网盘
- ✅ 升级到团队模式 — 数据存在服务器，不会丢
- ❌ 已经丢了的数据无法恢复（这就是「导出」的代价）

### 原因 2：开了无痕模式

无痕窗口**不会持久化**任何东西。

**解决**：用普通窗口打开 `.html` 文件，不要用无痕窗口。

### 原因 3：浏览器自动清缓存

有些浏览器（尤其是 Safari）会自动清理 `localStorage`。

**解决**：

1. 检查浏览器设置 → 隐私 / Cookie / 网站数据 → 把 casemap 域名（或 `file://`）加白名单
2. 或者换 Chrome / Edge（对 `localStorage` 更友好）

### 原因 4：多浏览器混用

你在 Chrome 上标的状态，在 Firefox 打开同一个 HTML 文件看不到 — 因为 `localStorage` 是浏览器独立的。

**解决**：只用一个浏览器；或用团队模式（数据在服务器，所有浏览器共享）。

## 节点不显示 / 看不到脑图

### 症状

- 打开 HTML 后页面空白
- 看到一片空白或「Loading…」一直转

### 排查

依次检查：

#### 1. 文件是否完整下载？

**症状**：HTML 里有乱码或只有几百字节。

**检查**：

- 文件大小：至少几十 KB（接口多的 spec 几 MB 也正常）
- 用文本编辑器打开（VS Code / Notepad），里面应该有完整的 HTML 标签

**解决**：重新下载 / 找开发重发。

#### 2. 浏览器版本太老？

**检查**：Chrome 90+、Edge 90+、Safari 14+、Firefox 88+。更老的浏览器可能不支持部分功能。

**解决**：升级浏览器，或换新电脑。

#### 3. 浏览器扩展拦截

有些扩展（广告拦截、隐私保护）会干扰 casemap 的脚本。

**解决**：

- 用无痕窗口打开（扩展默认禁用）
- 或者在浏览器扩展设置里把 casemap 域名加白名单

#### 4. JavaScript 被禁用

casemap 脑图是动态生成的，需要 JavaScript。

**检查**：浏览器设置 → 隐私 / 安全 → JavaScript → 允许。

**解决**：开启 JavaScript。

## 进度条不动

### 症状

- 你标了「通过」，但顶部进度条还是 0%
- 进度数字和实际标的不一致

### 排查

#### 1. 状态没真的标上

**检查**：节点边框变绿了吗？如果没变，说明标记操作没成功。

**可能原因**：

- 点了节点但没点右侧「Pass / Fail」按钮（只点节点 = 只查看，不标记）
- 网络慢，标记请求没发出去（团队模式）

**解决**：重新点节点 → 点对应状态按钮。

#### 2. 用了「重置」按钮

不小心点了重置，状态回到未测。

**解决**：重新标。

#### 3. 团队模式：网络断了一会

casemap 实时同步依赖网络。如果断了，你的标记会先存本地，等网络恢复才上传 — 进度条在这期间可能显示「旧」值。

**解决**：等几秒，或刷新页面。

#### 4. bug

如果上面都排除了，可能是 casemap 的 bug。

**解决**：

- 截图 + 描述发给项目 owner
- 临时解决方案：刷新页面（会触发重新加载）

## 服务器连不上

### 症状

- 浏览器访问 `http://服务器IP:8765` 打不开
- 一直转圈 / 「无法连接」 / 「连接超时」
- 「502 Bad Gateway」

### 排查步骤

#### 第 1 步：服务器在跑吗？

让 IT 在服务器上跑：

```bash
docker ps                  # 看 casemap 容器是否在运行
# 或
ps aux | grep casemap      # 看 casemap 进程
curl http://localhost:8765/health  # 看本机能否访问
```

如果容器没在跑：

```bash
docker compose up -d       # 重启
```

#### 第 2 步：IP 地址对吗？

**症状**：用旧地址连不上（可能 IP 变了）。

**解决**：让 IT 重新告诉你服务器地址。也可以试：

- 域名（`http://casemap.company.com`）
- localhost（如果在你本地）
- 127.0.0.1

#### 第 3 步：端口对吗？

casemap 默认用 8765。但有些公司：

- 改了端口（问 IT）
- 前面套了 Nginx（用 80 或 443 访问）
- 公司 VPN / 代理会改端口

**解决**：让 IT 告诉你准确的端口。

#### 第 4 步：防火墙

公司防火墙可能拦了非标准端口（8765 是非标准）。

**解决**：让 IT 把 8765 加白名单；或者把 casemap 放在 443 / 80（Nginx 反代）。

#### 第 5 步：内网 vs 公网

casemap 服务器在阿里云 ECS 上，但你的电脑在公司网络里 — 可能不通。

**解决**：

- 如果只是公司内部用，让 casemap 部署在公司内网服务器
- 如果要外网访问，配置 Nginx 反代 + SSL + 鉴权

#### 第 6 步：Docker 网络问题

**症状**：服务器能 `curl localhost:8765`，但你从外部连不上。

**可能原因**：Docker 没把端口暴露出来。

**解决**：检查 `docker-compose.yml`：

```yaml
ports:
  - "8765:8765"  # 必须有这一行
```

如果用 `docker run`，要有 `-p 8765:8765`。

#### 第 7 步：资源耗尽

**症状**：服务器一启动就死 / 一访问就崩。

**检查**：

```bash
docker stats  # 看内存 / CPU
df -h         # 看磁盘
```

casemap 本身很轻量，但 SQLite 数据库太大（>10GB）或磁盘满会出问题。

**解决**：清理磁盘，或迁移到 PostgreSQL（v1.2+ 支持）。

## WebSocket 断了 / 队友看不到改动

### 症状

- 你在 A 浏览器改了状态
- B 浏览器没自动更新（一直转圈 / 旧状态）

### 排查

#### 1. 看页面右上有「已连接 / 已断开」标志

casemap 团队模式的脑图页面右上有 WebSocket 状态指示器：

- 🟢 已连接：实时同步正常
- 🟡 重连中：网络抖动
- 🔴 已断开：长时间连不上

#### 2. 网络问题

最常见原因：你的网络到服务器之间的连接被中间设备断了（公司代理、防火墙、Nginx 超时设置）。

#### 4. 看服务器日志

让 IT 看服务器日志：

```bash
docker logs casemap
```

搜索 `WebSocket`、`broadcast`、`disconnect`。

#### 5. Nginx 反代没开 WebSocket

如果前面套了 Nginx，需要加 WebSocket 支持：

```nginx
location /api/v1/ {
    proxy_pass http://casemap_backend;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 86400;  # WebSocket 长连接
}
```

否则 Nginx 会在 60 秒后断开连接。

#### 6. casemap 自动重连机制

casemap 客户端会自动重连：

- 断线后 1 秒试一次
- 失败后 2 秒、4 秒、8 秒、16 秒… 最多 30 秒一次
- 重连成功后自动同步

所以**断网一会儿不需要做任何事**。

## API Key 输错 / 忘记了

### 症状

- 「Sign in」页输入 API Key 后报 401 / 403
- 「Invalid API Key」

### 排查

#### 1. 复制时漏字符 / 多空格

**最常见**。API Key 40+ 字符，复制时容易：

- 漏最后一个字符
- 多了换行 / 空格

**解决**：

- 让 PM 重新发（最稳）
- 或者从保存的地方（密码管理器 / 文档）重新复制
- 仔细核对前后字符

#### 2. 复制了别的 key

可能在密码管理器里有多个 casemap 项目的 Key，复制错了。

**解决**：让 PM 重新发你这个项目的 Key。

#### 3. 粘贴到了别的地方

比如粘贴到「Project name」输入框而不是「API Key」输入框。

**解决**：重新打开首页，输入到正确框。

#### 4. 真的丢了

**没保存** = 没别的办法恢复（v1 不支持找回）。

**解决**：

- v1.0 没有 key 找回功能
- 让 PM **新建一个项目**（重新生成 key），老的项目数据迁移过去 — 或者放弃

**未来**：v1.1+ 会支持 key 找回 / 重置。

## 上传接口文档失败

### 症状

- 上传 spec 文件后报错
- 「Invalid spec format」「Unsupported format」

### 排查

#### 1. 文件不是 JSON？

casemap **只支持 JSON 格式**的接口文档。

- ❌ YAML（v1 不直接支持，需要先转 JSON）
- ❌ Word / PDF / Markdown（不支持）

**解决**：让开发从 Swagger / Apifox / Postman **重新导出为 JSON**。

#### 2. JSON 不是合法格式？

**症状**：报错里有「JSON parse error」「Invalid JSON」。

**检查**：用文本编辑器打开，应该看到标准 JSON 结构（`{...}` 或 `[...]`）。

如果不是 JSON 格式（比如 HTML / 错误页），是导出出了问题。

**解决**：让开发重新导出。

#### 3. 格式 casemap 不识别？

**支持的格式**：

- OpenAPI 3.x
- Swagger 2.0（OpenAPI 1.x 也叫 Swagger）
- Postman v2.1
- Apifox（导出 OpenAPI）

**解决**：让开发确认 spec 格式；如果是老旧版本，升级后再导出。

#### 4. 文件太大？

**症状**：上传到一半断开 / 超时。

**检查**：文件大小。casemap 本身能处理几 MB 的 spec，但服务器可能限制上传大小。

**解决**：

- 让开发精简 spec（删除历史 endpoint）
- 让 IT 调大 Nginx 的 `client_max_body_size`

## 报告内容看不懂

### 症状

- 报告里全是英文术语
- 报告里没有备注
- 报告里失败原因不清楚

### 排查

#### 1. 英文 vs 中文

**症状**：报告里全是英文。

**原因**：LLM 重写没启用，casemap 用了原始的接口文档描述（英文）。

**详细动作**：让开发用 `--llm` 重新生成脑图。

```bash
uv run casemap generate spec.json -o cases.html --llm --model deepseek-chat
```

#### 2. 没有失败备注

**症状**：报告里「失败用例」清单只有标题，没备注。

**原因**：QA 标「失败」时**没写备注**。

**解决**：

- 让 QA 补充备注（标完一个就写一个）
- 团队模式：直接打开节点写
- 离线模式：再标一次（带备注）

#### 3. 备注写得太简单

**症状**：备注是「不对」「挂了」。

**解决**：参考 [QA 工作流 - 写失败备注](./tester-workflow.md#写失败备注)，用模板：

```
【复现步骤】1. xxx 2. xxx
【预期】xxx
【实际】xxx
```

## 性能问题（脑图卡顿）

### 症状

- 打开脑图慢（>5 秒）
- 拖动 / 缩放卡顿
- 节点多的时候页面卡死

### 排查

#### 1. 用例数量太多？

**症状**：几百到上千个节点。

**解决**：

- 用左侧筛选，只看某个模块 / 某个状态
- 切换到「表格视图」
- 拆分成多个项目（按模块）

#### 2. 浏览器 / 电脑太老

**解决**：换新电脑 / 升级浏览器。

#### 3. 内存不足

**症状**：浏览器内存占用 >2GB。

**解决**：

- 关其他 tab
- 重启浏览器
- 升级电脑内存

#### 4. 服务器慢（团队模式）

**检查**：进度页面加载速度。慢的话服务器有问题。

**解决**：让 IT 看服务器 CPU / 内存 / 数据库。

## 浏览器兼容性

### 完全支持的浏览器

- ✅ Chrome 90+
- ✅ Edge 90+
- ✅ Firefox 88+
- ✅ Safari 14+（macOS Big Sur+）
- ✅ 任何 Chromium 内核的现代浏览器

### 不支持

- ❌ IE 11（已停止支持）
- ❌ 360 浏览器（部分版本内核太老）
- ❌ QQ 浏览器（默认模式内核可能太老，建议切到极速模式）
- ❌ 微信内置浏览器（不支持 WebSocket，团队模式实时同步不工作）

### 移动端

- ✅ iOS Safari 14+
- ✅ Android Chrome 90+
- ⚠️ 脑图在小屏上显示拥挤，建议用电脑
